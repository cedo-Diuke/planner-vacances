# 🌍 Planner Vacances Famille

Application de planification de vacances — vols, hôtels, voiture, activités optimisées par IA.

## 🚀 Installer sur iPhone (sans App Store)

1. Ouvrez **Safari** sur iPhone
2. Allez sur `https://VOTRE-USERNAME.github.io/planner-vacances`
3. Appuyez sur **⬆️ Partager**
4. Appuyez sur **"Sur l'écran d'accueil"**
5. L'icône 🌍 apparaît comme une vraie app !

## 📦 Déployer sur GitHub Pages

1. Créez un repo GitHub nommé `planner-vacances`
2. Uploadez tous ces fichiers :
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
3. Allez dans **Settings → Pages → Source → main**
4. Votre app est live sur `https://VOTRE-USERNAME.github.io/planner-vacances`

## ✨ Fonctionnalités

- ✈️ Vols aller-retour
- 🏨 Hôtels avec check-in/check-out
- 🚗 Location de voiture et trajets
- 📍 Adresses à visiter (regroupement géographique)
- 😴 Jours de repos automatiques
- ⭐ Meilleurs moments de visite
- 📅 Ajout direct au calendrier iPhone
- 🗺️ Lien Plans (Apple Maps) sur chaque adresse
- 📴 Fonctionne hors ligne
